# Surya || AI Engineer Portfolio

Selamat datang di repositori kode sumber untuk portofolio profesional saya sebagai AI Engineer. Portofolio ini dirancang menggunakan teknologi web modern untuk menampilkan keahlian, pengalaman, dan studi kasus produk AI yang telah saya kerjakan.

## 🚀 Fitur Utama

- **Modern & Premium Design**: Antarmuka pengguna (*user interface*) dibangun menggunakan pendekatan *glassmorphism*, tipografi modern, dan tata letak yang bersih.
- **Project Case Studies**: Halaman detail untuk produk-produk spesifik yang mencerminkan pemahaman sistem AI dari ujung ke ujung (*end-to-end*), seperti **MLenz** (Vision), **Mzone** (Monitoring), dan **MIA** (RAG Assistant).
- **Responsive Layout**: Sepenuhnya dioptimalkan untuk perangkat *mobile* maupun *desktop* menggunakan fungsionalitas CSS Grid dan Flexbox.
- **Fast & Lightweight**: Dikembangkan dengan Vanilla CSS untuk memastikan beban (*bundle size*) tetap ringan dan performa maksimal.

## 🛠️ Tech Stack Website

Situs web ini dibangun di atas:
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Bahasa**: TypeScript
- **Styling**: Vanilla CSS (`globals.css`)

Sedangkan untuk *tech stack* keahlian AI Engineering yang ditampilkan dalam portofolio mencakup:
- **Modeling**: PyTorch, scikit-learn, Numpy, Pandas
- **LLM Stack**: OpenAI, LlamaIndex, Vector DB, RAG Pipeline
- **Backend & API**: FastAPI, Python
- **Infrastructure**: Docker, Linux, Edge AI (Jetson)

## 💻 Cara Menjalankan Secara Lokal (Local Setup)

Ikuti langkah-langkah berikut untuk menjalankan versi *development* dari situs ini:

1. **Clone repositori ini**
   ```bash
   git clone https://github.com/Shavrozky/surya_portfolio.git
   cd surya-portfolio
   ```

2. **Instal dependensi**
   ```bash
   npm install
   ```

3. **Jalankan *development server***
   ```bash
   npm run dev
   ```

4. Buka [http://localhost:3000](http://localhost:3000) di browser pilihan Anda untuk melihat hasilnya.

## 📁 Struktur Direktori Utama

- `app/` - Berisi *layout* utama, halaman depan (`page.tsx`), dan aturan *routing* untuk detail proyek (`/projects`).
- `app/globals.css` - File pondasi *styling* dengan utilitas untuk tema gelap (*dark theme*) dan panel kaca (*glass-panel*).
- `data/` - Repositori mini untuk data konten seperti teks deskripsi, daftar keahlian, dan modul proyek untuk kemudahan pembaruan.
- `public/` - Tempat penyimpanan aset statis seperti gambar dan video (*hero-visual*).
